Why dark sites need special typography attention

On a light site, whitespace and content do the heavy lifting. On a dark site, typography IS the design.

When your background is near-black, there are almost no visual elements to create hierarchy — no colored section backgrounds, no bold dividers, no contrasting panels. The entire visual hierarchy of your page is created by font size, font weight, and text opacity alone. If your type system is weak, every section collapses into a flat wall of similar-looking text. Your notes said "the right fonts make a site feel more sophisticated than the brand actually is" — on a dark site this effect is 2× stronger because fonts are the primary visual element.

On #050505, a well-chosen font at the right size hierarchy creates the perception of premium quality before a single word is read. A default font at muddled sizes creates "AI slop" — the appearance of a site that wasn't designed, just generated.

Why 800+ weight looks wrong on dark specifically

On a white background, 800 weight looks bold. On a near-black background, 800 weight looks aggressive and corporate — the extra thick strokes create too much visual tension against the dark. The eye reads heavy weight on dark as "shouting" rather than "authoritative." Stick to 700 maximum for the hero headline, 600 for everything else that needs emphasis. The contrast between 700 headline and 400 body on dark creates more than enough visual hierarchy.

Complete CSS — copy this into your stylesheet and you're done
Typography system — paste into your CSS file
/* ── GOOGLE FONTS IMPORT (put in <head> or top of CSS) ── */
@import url('https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@400;500;600;700&display=swap');

/* ── FONT VARIABLES ── */
:root {
  --font-primary: 'Plus Jakarta Sans', -apple-system, sans-serif;
  /* Use same font for both — no second font needed */
}

/* ── BASE ── */
body {
  font-family: var(--font-primary);
  font-size: 15px;
  font-weight: 400;
  line-height: 1.7;
  color: rgba(255,255,255,0.55);
  -webkit-font-smoothing: antialiased; /* critical on dark */
  -moz-osx-font-smoothing: grayscale;
}

/* ── HEADINGS ── */
h1 {
  font-size: clamp(36px, 5vw, 56px); /* fluid — big on desktop, right on mobile */
  font-weight: 700;
  line-height: 1.1;
  color: #F5F5F0;
  letter-spacing: -0.02em; /* slight tighten on large display sizes */
}
h2 {
  font-size: clamp(24px, 3vw, 36px);
  font-weight: 600;
  line-height: 1.2;
  color: #F5F5F0;
  letter-spacing: -0.01em;
}
h3 {
  font-size: clamp(18px, 2vw, 22px);
  font-weight: 600;
  line-height: 1.3;
  color: #F5F5F0;
}

/* ── TEXT UTILITY CLASSES ── */
.text-primary { color: #F5F5F0; }
.text-secondary { color: rgba(255,255,255,0.55); }
.text-muted { color: rgba(255,255,255,0.30); }
.text-accent { color: #1DB574; }

/* ── EYEBROW / LABEL ── */
.eyebrow {
  font-size: 10px;
  font-weight: 600;
  letter-spacing: 0.08em;
  text-transform: uppercase;
  color: #1DB574;
}

/* ── SUBHEADLINE ── */
.subheadline {
  font-size: 17px;
  font-weight: 400;
  line-height: 1.6;
  color: rgba(255,255,255,0.65);
  max-width: 580px;
}

/* ── ONE CRITICAL RULE FOR DARK SITES ── */
* {
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
}
The most overlooked CSS property for dark sites

-webkit-font-smoothing: antialiased — the single line that makes all fonts look premium on dark

By default, browsers use "subpixel antialiasing" which renders fonts slightly heavier by using red/green/blue subpixels. On white backgrounds this looks fine. On dark backgrounds it makes text look slightly blurry, thick, and cheap — especially on Retina/HiDPI screens. Setting -webkit-font-smoothing: antialiased tells the browser to use pure grey antialiasing, which makes text look razor-sharp and thin on dark backgrounds. This is what makes Apple's dark mode text look crisp. Without it, even a premium font looks slightly off on your #050505 background.

Add this to both * and body. It costs nothing, takes 2 seconds, and immediately improves every single text element on your site on dark backgrounds. It is the hidden reason premium dark sites look different from amateur ones.
Do this / never do this
Do this
  • Use Plus Jakarta Sans or Outfit — both free on Google Fonts
  • Add -webkit-font-smoothing: antialiased to body and *
  • Use clamp() for fluid font sizes that scale with viewport
  • letter-spacing: -0.02em on H1 (tightens large display type)
  • letter-spacing: 0.08em only on 10px uppercase eyebrow labels
  • line-height: 1.7 on all body copy — non-negotiable
  • line-height: 1.1 on hero H1 — tight is correct at large sizes
  • Use 3 weights max: 400 · 600 · 700 (hero only)
  • Set max-width: 600–680px on all paragraph text blocks
  • Load fonts with display=swap to prevent flash of unstyled text
Never do this
  • Use Roboto, Open Sans, or Lato — too generic, zero premium signal
  • Use any serif font on a dark background
  • Use font-weight 800 or 900 on dark — looks aggressive
  • Use letter-spacing on body text — looks like AI design
  • Use letter-spacing on headlines — breaks the optical fit
  • Use more than 2 typefaces (1 is ideal, 2 maximum)
  • Set body font-size below 15px on a dark background
  • Use line-height below 1.6 on any paragraph text
  • Skip font smoothing — it ruins text on dark backgrounds
  • Use pure white (#ffffff) for text — use #F5F5F0 instead
