Anatomy — every element and why it's there
Dark overlay
A semi-transparent dark layer (rgba 0,0,0,0.55) covers the entire page behind the popup. This creates focus — the visitor's eye has nowhere to go except the popup. Clicking the overlay closes the popup (this is the expected browser behaviour and must work).
backdrop: rgba(0,0,0,0.55) · backdrop-filter: blur(3px) on modern browsers · click-to-close on the overlay itself
Left accent bar
A 4px vertical bar in your brand teal/green on the left edge of the popup card. Subtle but effective — it signals brand identity and premium quality without adding visual noise. Your custom estimator had this dark card design — this is the lighter-background equivalent.
4px wide · full card height · brand color (#0F6E56 or your equivalent) · no border-radius
Close button (✕)
Top-right corner. Small circle, 24px. Must be immediately visible and work on first click. This is non-negotiable — a popup that traps visitors destroys trust instantly. Also must close on Escape key press and on clicking the dark overlay.
Three close triggers: ✕ button click · Escape key · clicking outside the card on the overlay
Eyebrow line
Small uppercase text above the headline: "Free · No obligation." Kills commitment anxiety before the visitor even reads the headline. Sets the emotional tone of the entire popup in 3 words.
"Free · No obligation" · "Takes 30 seconds" · "No sales pitch" — pick the fear you most need to kill first
Headline
Direct and specific — names the exact action. Not "Get in touch" or "Contact us." The visitor just clicked "Book a Free Inspection" — the popup headline must confirm exactly that action so they feel they're in the right place.
"Book your free roof inspection" — mirrors the button text exactly. Never a surprise or redirect.
Subheadline
One sentence that answers "what happens after I submit?" The visitor needs to know what the next step is before they commit to filling the form. "We'll call you within 2 hours" sets a clear expectation and removes the fear of submitting into a void.
"Takes 30 seconds. We'll call you within 2 hours to confirm your slot." — time to fill + response time + what happens next
3 fields only
Name · Phone · Zip code. Nothing else. No email (you have the phone), no address (you'll get it on the call), no "describe your problem" textarea (you'll ask on the call). Every additional field drops conversion rate. Your notes were explicit: "Only collect 2–3 bits of info — get everything else over the phone."
Name → Phone → Zip. Tab order must flow naturally downward. No optional fields. No dropdowns.
Green checkmark on valid input
The moment a field passes validation (name has 2+ chars, phone has 10 digits, zip has 5 digits), a small green checkmark appears inside the right edge of the field and the border turns green. This is the micro-interaction from your notes — positive reinforcement that creates momentum through the form.
Appears on blur (when the visitor leaves the field) · green border + green ✓ icon inside field · instant visual reward
Submit button
Full width, brand color, direct action text. "Book My Free Inspection →" — first person ("My") makes it feel like their action not yours. Arrow signals forward movement. Never "Submit" or "Send."
"Book My Free Inspection →" · disabled state when fields are invalid (lighter opacity) · loading spinner on click while submitting
Trust micro-signals
Three tiny dot-separated reassurances below the button. At the exact moment of commitment these kill last-second doubt. Keep them to 2–3 words each so they can be read in under a second.
"No commitment · Same-day available · Licensed & insured" — three fears, three kills, zero extra space needed

JavaScript — complete mechanism (open · close · validate · submit · success)
const popup = document.getElementById('inspection-popup');
const formState = document.getElementById('popup-form-state');
const succState = document.getElementById('popup-success-state');
const submitBtn = document.getElementById('popup-submit');
let scrollFired = false, exitFired = false;

// ── OPEN / CLOSE ──
function openPopup() {
  popup.classList.remove('hidden');
  document.body.style.overflow = 'hidden'; // lock scroll
  setTimeout(() => document.getElementById('f-name').focus(), 300);
}
function closePopup() {
  popup.classList.add('hidden');
  document.body.style.overflow = ''; // unlock scroll
  setTimeout(resetPopup, 400); // reset after fade
}
function resetPopup() {
  formState.classList.remove('hidden');
  succState.classList.add('hidden');
  document.getElementById('inspection-form').reset();
}

// ── TRIGGERS ──
document.querySelectorAll('.cta-inspection')
  .forEach(btn => btn.addEventListener('click', openPopup));
document.querySelector('.popup-backdrop')
  .addEventListener('click', closePopup);
document.querySelectorAll('.popup-close')
  .forEach(btn => btn.addEventListener('click', closePopup));
document.addEventListener('keydown', e => { if(e.key==='Escape') closePopup(); });

// 15-second scroll trigger (fires once)
window.addEventListener('scroll', () => {
  if(!scrollFired) { scrollFired=true; setTimeout(openPopup, 15000); }
});

// Exit intent — desktop only
document.addEventListener('mouseleave', e => {
  if(e.clientY < 10 && !exitFired) { exitFired=true; openPopup(); }
});

// ── VALIDATION ──
function validate(id, testFn) {
  const el = document.getElementById(id);
  el.addEventListener('blur', () => {
    el.classList.toggle('valid', testFn(el.value));
    checkAllValid();
  });
}
validate('f-name', v => v.trim().length >= 2);
validate('f-phone', v => v.replace(/\D/g,'').length >= 10);
validate('f-zip', v => /^\d{5}$/.test(v.trim()));
function checkAllValid() {
  const allOk = ['f-name','f-phone','f-zip'].every(
    id => document.getElementById(id).classList.contains('valid'));
  submitBtn.disabled = !allOk;
}

// ── SUBMIT ──
document.getElementById('inspection-form')
  .addEventListener('submit', async (e) => {
    e.preventDefault();
    submitBtn.textContent = 'Booking...';
    submitBtn.disabled = true;
    const name = document.getElementById('f-name').value;
    await fetch('YOUR_FORM_ENDPOINT', {
      method: 'POST',
      headers: {'Content-Type': 'application/json'},
      body: JSON.stringify({
        name, phone: document.getElementById('f-phone').value,
        zip: document.getElementById('f-zip').value
      })
    });
    // Show success state with their name
    document.getElementById('success-name').textContent =
      `You're booked, ${name.split(' ')[0]}. We'll call you within 2 hours.`;
    formState.classList.add('hidden');
    succState.classList.remove('hidden');
    setTimeout(closePopup, 5000); // auto-close after 5s
  });
Where to send the form data — 3 options ranked easiest to hardest
Option 1 — easiest

Formspree

Sign up at formspree.io, create a form, get an endpoint URL. Replace "YOUR_FORM_ENDPOINT" with it. Formspree emails you every submission instantly. Free tier handles 50 submissions/month.

Endpoint: https://formspree.io/f/yourformid — zero backend code needed.
Option 2 — if on Netlify

Netlify Forms

Add netlify to your form tag. Netlify auto-detects it and creates a submissions dashboard. Free up to 100 submissions/month. Also sends email notifications.

Zero cost if already on Netlify. The cleanest solution if your site is already deployed there.
Option 3 — best for roofing

Custom API + SMS (Twilio)

Build a small serverless function (Netlify Function or Vercel) that receives the form data and sends you an SMS via Twilio. You get a text the second someone books. Fastest possible response time.

For roofing especially — getting a text within seconds means you can call back in under 2 minutes, which converts at a dramatically higher rate than an email notification you read an hour later.
Field validation rules — exactly what to check
Name field
Minimum 2 characters after trim · any characters allowed · validates on blur (when they leave the field)
❌ "J" — too short
✓ "Jo" — valid · "Sarah M." — valid
Phone field
Strip all non-digits first, then check length ≥ 10 · accepts (555) 000-0000, 5550000000, 555-000-0000 all equally
❌ "555-000" — only 6 digits
✓ "(555) 000-0000" — 10 digits
Zip code field
Exactly 5 digits · numeric input only (inputmode="numeric") · maxlength="5" prevents overlength · US only
❌ "9021" — only 4 digits
✓ "90210" — exactly 5 digits
Do this / never do this
Do this
  • 3 fields maximum: name, phone, zip
  • Auto-focus the name field when popup opens
  • Show green ✓ on valid fields immediately
  • Disable submit button until all 3 fields valid
  • Lock body scroll when popup is open
  • Close on: ✕ button, Escape key, backdrop click
  • Show personalised success state with their first name
  • Auto-close success state after 5 seconds
  • Get SMS notification — call back within 2 minutes
  • Wire every "Book Inspection" button to same popup
Never do this
  • Add more than 3 fields — kills conversion
  • Add an email field — you have their phone
  • Redirect to a new page — always a modal
  • Make the popup hard to close
  • Skip the success state — visitor needs confirmation
  • Use generic success: "Thank you for your submission"
  • Fire the scroll/exit trigger more than once per session
  • Leave submit button active on invalid fields
  • Check email for leads — set up SMS so you respond fast
  • Have the popup freeze body scroll permanently on close

The most important mechanic nobody talks about — response time

The popup itself is only half the mechanism. The other half is how fast you call back. Studies on lead response time consistently show that calling back within 5 minutes of a form submission converts at 4–8× the rate of calling back an hour later. For roofing especially — where the homeowner is often stressed about an active problem — being the first contractor to call after they submit the form is often the entire reason they book with you and not a competitor. Set up SMS notifications so you get a text the moment the form submits. That text contains their name and phone number. You call within 2 minutes. That speed is a conversion mechanism in itself.
